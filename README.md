# EcoBuild-AI

## Pré-requisito — Google AI Studio

Antes de executar o `script.sh`, é necessário possuir uma **conta Google** com acesso ao **Google AI Studio**.

O script utiliza a `GOOGLE_API_KEY` para configurar a integração com os serviços de Inteligência Artificial da aplicação.

### Antes de executar o script

1. Aceda ao **Google AI Studio**.
2. Inicie sessão com a sua conta Google.
3. Crie ou obtenha uma **API Key**.
4. Tenha a chave disponível quando executar o script.

Durante a execução, o `script.sh` irá solicitar a sua `GOOGLE_API_KEY`:

```text
Digite a GOOGLE_API_KEY:
```

Introduza a chave quando solicitado.
